# UNIDAD-1-EJERCICIO-10
Resolución del ejercicio N°10 de la unidad 1 de programación 2.
El programa muestra como se desarrolla el ciclo de vida de un proyecto.
Por consola muestra las 3 fases: Analisis-Desarrollo-Despliegue.
Si se quiere avanzar un fase más, el programa devuelve un mensaje de error.
